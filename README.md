# 盆景蟠扎造型推演系统

浏览器内的盆景造型推演工具：给桩材建档、编辑骨架、蟠扎缠丝、弯枝修剪、按年推演、观赏面构图检查与养护计划排程。TypeScript + three.js + IndexedDB，无后端。

## 运行

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5180）
npm run build      # 类型检查 + 生产构建
npm run test:smoke # 纯数学冒烟测试（无需浏览器/GPU）
```

首次进入「桩材档案」页点 **载入 5 棵测试老桩**，包含四树种手工老桩（其中真柏带舍利干与神枝）和一棵 3000+ 节点的压测树，数据写入 IndexedDB。

## 页面

| 路由 | 功能 |
| --- | --- |
| 桩材档案 | 按树种建档（五针松/真柏/榆树/三角梅），节点带粗度与类型 |
| 骨架编辑 | 3D 点选节点，改位置/粗度/类型，增删子枝 |
| 蟠扎造型 | 选铝丝/铜丝与号数，点选路径生成 45° 螺旋缠丝，支持分叉换向与双枝蟠扎 |
| 弯枝修剪 | 直接拖拽弯枝（实时最小弯曲半径校验、超标标红）、修剪伤口、舍利/神枝、疏叶、年度推演 |
| 观赏面预览 | 定正面、配盆几架、侧光层次、剪影三角构图与主干倾角检查 |
| 养护计划 | 按方案自动排上丝/拆丝/修剪/换盆，勒痕风险提前预警 |
| 方案对比 | 同桩最多三个方案并排，相机视角联动 |
| 设置 | 主题、默认丝材、接触精度阈值、IndexedDB 导入导出 |

## 核心架构

### 蒙皮而非每帧重建网格（性能关键）

- **静止姿态一次构建**焊接无缝树皮网格：渐缩管环 + 分叉处面积法则焊接球 + 根盘喇叭口/板根；`src/three/meshBuilder.ts`。
- 每个顶点带最多 4 骨蒙皮权重，弯枝只更新骨骼矩阵（GPU 蒙皮），3000 节点 FK 实测约 0.5ms/帧，拖拽跟手。
- 结构变更（修剪、舍利、年度生长、缠丝增删）才重建网格；纯弯曲零重建。

### 缠丝贴合保证（精度关键）

`src/three/wireBuilder.ts` 中丝中心线 = 树皮表面点沿径向外偏 `barkR + wireR`，且**丝顶点复制同站位树皮顶点的同一组蒙皮权重**。线性混合蒙皮下两者变换完全一致，因此无论骨架怎么弯，丝-皮相对间隙在静止与姿态空间恒等——冒烟测试实测弯后相对距离误差 0.000%，远优于丝径 10% 的红线。

### 注意：skinIndex 类型

three.js 蒙皮着色器把 `skinIndex` 声明为 `vec4`（浮点），因此几何属性必须用 `THREE.Uint16BufferAttribute`（归一化无符号整型），不能用普通 `BufferAttribute(Uint32Array)`，否则整型属性走 I-Pointer 绑定到 float vec4 会读到垃圾索引、顶点飞散。

### 年度推演

`src/core/simulation.ts`：枝条按树种速率增粗；缠丝超过树种留园年限未拆则生成螺旋勒痕（相位对齐缠丝），拆丝后勒痕与伤口按年自愈长平。网格的勒痕槽在 `meshBuilder.edgeRadiusAt` 里按相位凹陷实现。
